description: Close out a session — write what was decided into the specs
---

Wrap up this session.

1. Work out which area this session touched: car sales, government, coaching, or
   the dashboard and architecture itself.
2. Read the matching spec under `docs/` before writing anything.
3. Update it with what this session actually established:
   - decisions made, and what they replace
   - numbers, rules and thresholds
   - anything in the existing spec that turned out to be wrong
   - new open questions, and any that are now answered — move those to the
     Resolved section of `docs/05-OPEN-QUESTIONS.md`
4. Keep the existing structure and edit in place. Do **not** append a changelog,
   a dated log, or a "session notes" section. The spec describes the current
   state of the business, not the history of how it was decided.
5. Record only what was **decided**. Things that were merely discussed do not go
   in the spec.
6. Commit with a message naming what changed, and push.
7. Finish with a handoff paragraph for the next session.

If nothing was decided this session, say so and write nothing.
